# BQDry Mini

<div class="div-table">

<ImageView src={require('@site/docs/more-series/bqdry-module/bqdry-mini/img/bqdry-mini-title.webp').default}  width="45%" class="right-image"/>

## Product Overview

BQDry Mini is a modular heating and drying system designed specifically for 3D printing filament management, with the first-generation Bambu Lab AMS as its primary officially supported platform. The system consists of a control module and two heating output modules. It can be installed directly inside the AMS to add active drying capabilities to a system that originally lacked active heating.

Powered by an independent 24V power supply, the BQDry Mini can operate continuously during normal AMS feeding and printing processes. It supports both physical buttons and a Web UI for control, allowing users to configure drying temperatures and duration. Additionally, it features print job linkage, which automatically starts drying when a print begins and stops it when the print finishes.

</div>

:::warning

The official installation guide for BQDry Mini currently applies only to the first-generation Bambu Lab AMS and is not compatible with the AMS 2 Pro. For any other enclosed heating applications, a separate evaluation regarding physical space, wiring, power supply, and thermal safety requirements is necessary. This Wiki does not provide a universal installation guarantee for other setups.

:::

## Key Features

- **AMS-Embedded Upgrade**: The control module and output modules are installed inside the AMS to maintain the original device appearance and usage as much as possible.
- **Non-Destructive Installation**: No irreversible drilling, cutting, or modifications to the AMS shell are required.
- **Dry While Printing**: Powered by an independent power supply, BQDry Mini can dry filaments continuously during normal AMS feeding and printing processes.
- **35–60$^{\circ}\mathrm{C}$ Temperature Control**: Supports heating temperature settings from 35$^{\circ}\mathrm{C}$ to 60$^{\circ}\mathrm{C}$.
- **Quick Physical Control**: Supports one-button start/pause/resume/stop, and provides five quick-select timer options: 4H, 8H, 12H, 24H, or continuous.
- **Web UI Control**: Allows users to configure network settings, adjust drying parameters, view device status, and bind printers via a web browser.
- **Adjustable Dehumidification**: Uses a replacement AMS handle to create an adjustable dehumidification channel, helping release moisture during the drying process and reducing condensation risks.
- **Print Job Linkage**: After binding with a compatible printer, the "Auto-Dry During Print" feature can be enabled to automatically start drying when a print job begins and stop heating when it ends.

## AMS Installation Guide

:::warning

1. Power Off: Turn off the printer and disconnect the connecting cable between the AMS and the printer.
2. Clear Filament & Tubes: Disconnect the AMS PTFE tube and remove all filaments from inside the AMS.
3. Handle with Care: Do not pull or strain the internal wiring of the AMS during the installation process.
4. Cable Clearance: All power cords and connecting wires must be kept clear of the AMS gears, rollers, and spool moving areas to avoid interference.
5. Keep Original Parts: It is highly recommended to keep the original AMS power motherboard after removal, in case you need to restore the device to its original factory state in the future.

:::

## Buttons and Indicators

<ImageView src={require('@site/docs/more-series/bqdry-module/bqdry-mini/img/control-module.webp').default}  width="100%" />

There are two physical buttons located on the top of the control module:

| Button / Indicator | Function |
| :--- | :--- |
| Timer Selection Button | In standby mode, press to cycle through the quick timers (4H / 8H / 12H / 24H / Continuous). |
| Start / Pause Button | In standby mode, press to start. During operation, short press to pause/resume, and long press to stop. |
| Timer Stage Indicators | Displays the currently selected quick-select timer stage. |
| Countdown Timer | Displays the remaining drying time; displays according to firmware definitions in continuous (unlimited) mode. |
| Humidity Level | Displays the ambient humidity level from H1 to H5. |
| Heating Status Indicator | Displays the current operating status when heating is actively running. |

### One-Click Start

When no quick-select timer stage is chosen, pressing the Start / Pause button will cause the device to begin heating using the temperature and duration settings last saved via the Web UI. The system will automatically stop heating once the countdown finishes.

During the heating process:

- Short Press **Start / Pause**: Pause or resume heating; the countdown timer will pause or resume simultaneously.
- Long Press **Start / Pause**: Stop the current heating session.

### Quick-Timer Drying

In standby mode, press the **Timer Selection** button to cycle through the following five stages:

`4H → 8H → 12H → 24H → Continuous (Unlimited)`

After selecting a duration, press the Start / Pause button. The device will begin heating according to the target temperature set in the Web UI and the currently selected quick-timer duration.

## Humidity Level Description

BQDry Mini uses H1 to H5 to indicate the current ambient humidity status. A higher level indicates a more humid environment.

<ImageView src={require('./img/humidity-level-guide.webp').default}  width="75%" />

| Humidity Level | Ambient Condition | Usage Recommendation |
| :---: | :--- | :--- |
| H1 | Dry | Ideal for filament storage and printing. |
| H2 | Relatively Dry | Suitable for normal storage and printing. |
| H3 | Slightly Humid | Recommended to start a filament drying session. |
| H4 | Humid | High recommendation to dry the filament. |
| H5 | Highly Humid | Strongly advised to dry the filament as soon as possible. |

:::warning

Humidity Level Availability: The humidity level readings are only functional when a compatible Bambu Lab printer is bound and the AMS is connected.

:::

:::info

Humidity Level Reference: The humidity levels reflect the general wetting or drying trend of the current environment. They do not represent precise relative humidity percentages (%) or the actual moisture content inside the filament. When H3, H4, or H5 is displayed, it is highly recommended to start a drying session with the BQDry Mini.

:::

## Web UI Initial Connection Guide

### Connect to the Device AP Hotspot

After powering on the device, open the Wi-Fi settings on your phone or computer and connect to the AP hotspot broadcasted by the BQDry Mini:

- Hot spot Name (SSID): `BQDry_Mini_XXXXXXXXXX`
- Default Password: `987654321`

### Access the Web UI

Once connected to the AP hotspot:

- Mobile Devices: The BQDry Mini Web UI may automatically pop up via a captive portal.
- Manual Access: Alternatively, you can open a web browser and input the default IP address: `192.168.254.1`.

:::info

Default Hotspot IP: 192.168.254.1, if your home router also uses the IP range 192.168.254.xxx, a subnet conflict will occur because the BQDry Mini shares the same network segment. This conflict will prevent the BQDry Mini from successfully binding to your printer. To resolve this, please manually modify the Hotspot IP of the BQDry Mini to a different subnet range (e.g., changing it to 192.168.253.1) so that it does not overlap with your router's network settings.

:::

### Wi-Fi Configuration

Upon first boot from the factory or after a factory reset, entering the Wi-Fi configuration page will automatically scan for nearby networks. You can also trigger a rescan manually by clicking the refresh button.

:::warning

Wi-Fi Compatibility: The device only supports 2.4GHz Wi-Fi networks. 5GHz Wi-Fi networks are not supported.

:::

Select the Wi-Fi network you want to join, and input the password.

## Factory Reset

Press and hold both physical buttons on the control module simultaneously for **more than 5 seconds** to trigger a factory reset.

A factory reset will clear or restore the following:

- Wi-Fi network connection information
- Bound printers
- Related device parameters and Web UI settings

Once the reset is complete, please reconfigure the device by following the [Web UI Initial Connection Guide](#web-ui-initial-connection-guide)

## Special Notes

### Continuous Heating Mode (Unlimited)

When the Continuous (Unlimited) stage is selected, the device will still execute its internal thermal protection logic. However, for maximum safety, it is highly recommended to operate the equipment only in an observable and monitored environment. Avoid leaving the device running unattended for extended periods.

### Dehumidification & Condensation

During the heating process, moisture from the filament will gradually be released into the air. It is advised to open an appropriate dehumidification channel using the AMS replacement handle based on the actual drying status to help expel moisture and reduce the risk of internal condensation.

### Hot Surfaces

While the heating system is running, the air outlets of the output modules and their surrounding areas may reach elevated temperatures. Do not block the air outlets, and avoid touching these high-temperature areas directly during operation.

### Shell Surface Texture

The shell of the BQDry Mini is made of a Nylon + Glass Fiber (PA-GF) composite material. This material may naturally exhibit surface textures resembling fine scratches or visible fibers. This is a normal and inherent characteristic of the material itself and not a product defect.
