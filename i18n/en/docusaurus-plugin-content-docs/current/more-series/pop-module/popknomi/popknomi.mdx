## Overview

**PopKnomi — Status with Personality, for Snapmaker U1**

    PopKnomi is a smart print-status display built for the Snapmaker U1. Its dynamic UI delivers real-time updates on printing, heating, leveling, error states, and more. You can track print progress and printer status at a glance without repeatedly checking your computer, phone, or the printer's touchscreen — all while adding a more distinctive visual touch to your setup.

- **Real-Time Status**

    Knomi UI brings printer status to life with real-time updates for printing, heating, leveling, errors, and more. Three progress views are available: Knomi Animation, Ring Progress, and Alternating Mode.

- **Custom UI and GIFs**

    Personalize interface colors and upload GIF animations to create a display that matches your preferences, giving your printer a more distinctive and interactive look.

- **Multiple Mounting Options**

    Install PopKnomi on the Snapmaker U1, pair it with PopCap, or place it on your desk. Position it wherever it works best for your setup and check printer status at a glance.

- **Wide Viewing Angle and OTA Updates**

    The wide-view color display keeps printer status clear from nearly any angle, while OTA support makes firmware updates quick and convenient, helping you stay current with the latest fixes and improvements.

## Initial Setup Guide

### Access Web UI

- Connect to the PopKnomi AP hotspot.

    After first startup or after running the `Restore Factory Settings` command, the following screen appears.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-ap-qr-code.webp').default} width="30%"/>

    Scan the QR code displayed on PopKnomi, as shown above, to obtain the name and password of its AP hotspot, then connect to it. The factory-default AP information is:

    ```text
    Wi-Fi Name: Pop_Knomi_xxxxxxxxxxxx
    Wi-Fi Password: 987654321
    ```

    If you cannot connect by scanning the QR code, manually connect to the hotspot from your device's `Settings` menu.

- After connecting to the AP, a `Connected (login/authentication required)` notification should appear. Tap it to open the Web UI configuration page. If the page does not open due to network conditions, wait 10–20 seconds. If it still does not open, enter [192.168.254.1](http://192.168.254.1) in a browser to access the Web UI.

### Connect Wi-Fi

- During initial setup, the `Select Language` page opens automatically. Set the language, then tap `Next`.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-language.webp').default} width="30%"/>

- On the Wi-Fi connection page, PopKnomi automatically scans for nearby Wi-Fi networks. Select the Wi-Fi network used by the printer. If the printer's Wi-Fi network is not listed, tap `Scan` to scan again.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-wifi.webp').default} width="30%"/>

- Wait for the connection to complete. When the dialog shown below appears, tap `Binding` to open the `Printer` page and bind a printer.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-goto-printer.webp').default} width="30%"/>

### Bind Printer

#### Automatic Scan

- On the Web UI `Printer` page, tap `Scan` to scan for printers on the same local network. A full scan takes about 30 seconds. If the desired printer is not found, tap `Scan` again or use `Manual Entry` to enter all information manually.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-printer.webp').default} width="30%"/>

- After the scan is complete, select the printer to connect to. Under normal conditions, the printer's default name is `lava`. Its `IP` address is filled in automatically after selection.

- Tap `Bind` to connect to the printer. A `Binding Successful` dialog confirms that PopKnomi has connected successfully.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-bind-ok.webp').default} width="30%"/>

- Your PopKnomi is now ready to use.

Contact customer support for further troubleshooting.

:::

## Web UI Guide

### Wi-Fi & IP

<ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-wifi-ip.webp').default} width="30%"/>

1. To reconfigure the Wi-Fi network used by PopKnomi, tap `Configure Wi-Fi` to open the Wi-Fi setup page.

    :::info[Note]

    After changing the Wi-Fi network, PopKnomi's local network and IP address will change. We recommend connecting your device to the PopKnomi AP hotspot before changing this setting. Otherwise, the connection between your device and PopKnomi will be interrupted while PopKnomi switches Wi-Fi networks.

    :::

2. After Wi-Fi setup is complete, connect your phone, computer, or other device to the same local network as PopKnomi. Enter the IP address in a browser's address bar to access the Web UI. To avoid forgetting the IP address, you can add it as a bookmark on your phone's home screen for quick access.

3. When your device is connected to the same local network as PopKnomi, you can access the Web UI by hostname. For example, the factory-default hostname is `PopKnomi`; enter [http://popknomi.local](http://popknomi.local) directly. Hostnames are not case-sensitive. If your device is using a VPN, hostname access may not work; use the IP address instead.

    You can customize the hostname, subject to the following rules:

    - It may contain only letters (a-z, A-Z), numbers (0-9), and hyphens (-), and the first character must be a letter.

    - It must be 8–32 characters long.

    After editing the hostname, tap `Set Hostname` to send the new hostname to PopKnomi. If the dialog shown below appears, the hostname has been updated successfully. A restart is required for the new hostname to take effect. Tap `OK` in the dialog to restart PopKnomi immediately. To postpone the restart, tap the `x` button in the upper-right corner of the dialog to close it.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-hostname.webp').default} width="30%"/>

### AP

:::info[Note]

- The AP is the Wi-Fi hotspot broadcast by PopKnomi, allowing phones and computers to connect directly to it. You can disable this hotspot if you do not want it to be broadcast. However, PopKnomi automatically re-enables it when it cannot connect to the configured Wi-Fi network. This provides a fallback connection method when the configured Wi-Fi network is unavailable.

- If your device accesses the Web UI through the PopKnomi AP hotspot, disabling the AP or changing its information disconnects the device from PopKnomi. To avoid this, connect your device to the same local network as PopKnomi, enter its IP address in a browser's address bar to access the Web UI, and then change this setting.

:::

<ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-ap.webp').default} width="30%"/>

1. Enable or disable the PopKnomi AP hotspot. After disabling the AP hotspot, you cannot use it to access the Web UI. Before disabling it, record PopKnomi's IP address on its current Wi-Fi network so a device on the same Wi-Fi network can access the Web UI by IP address.

2. Modify the PopKnomi AP hotspot. The default settings are:

    ```text
    Wi-Fi Name: Pop_Knomi_xxxxxxxxxxxx
    Wi-Fi Password: 987654321
    ```

    No restart is required after making changes. PopKnomi recreates the new AP hotspot in the background.

3. This is PopKnomi's IP address on the AP hotspot network. Restart PopKnomi in order for changes to this IP address to take effect.

### Theme

<ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-theme-1.webp').default} width="30%"/>

1. `Print Progress`

    - `Display only Printing Data`: During printing, the display shows real-time print progress ring, remaining time, and print layer height.

    - `Display only GIF`: During printing, the display shows the Knomi animation only.

    - `Display Printing Data and GIF alternately`: During printing, the display alternates between real-time print information and the Knomi animation every 10 seconds.

    - `Percentage Overlay on GIF`: During printing, the display shows the Knomi animation with the print-progress percentage at a specified position.

2. `Error Display Mode`

    - `Error Display Off`: Do not capture this printer status.

    - `Error Display QR`: When the printer has an error code, the display shows a QR code for the corresponding wiki page.

    - `Error Display GIF`: When the printer has an error code, the display shows the print-error GIF.

3. `Screen Off`

    - `Disabled`: Do not turn off the display backlight.

    - `Screen off on standby`: When the printer is idle, turn off the display backlight instead of showing the standby GIF.

    - `Screen off after 30 minutes on inactivity`: Turn off the display backlight if the printer status has not changed for 30 minutes.

4. `All GIF Colors`: Change the color of all Knomi animations at once.

5. `Progress Color`: Change the color of real-time print progress ring, remaining time, print layer height, and other information.

## Restore Factory Settings

:::warning

Restoring PopKnomi to factory settings clears all configuration, including the language, connected Wi-Fi network, custom hostname, custom AP hotspot name and password, and bound printer information. However, custom GIFs cannot be restored to factory GIFs. GIFs can only be changed by uploading GIFs or updating an IMG file.

:::

### Restore via Web UI

- Open the `Settings` page and tap `Factory Reset`. A confirmation dialog appears. Confirm the factory reset, and PopKnomi restores factory settings and restarts.

### Update Firmware

#### OTA

- On the Web UI `Settings` page, tap `Select .bin File`, then select the firmware to update, for example: pop_knomi_01.00.00.01.bin. The device restarts automatically after the update is complete.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-fw.webp').default} width="30%"/>

#### flash_download_tool (Type-C Flashing)

:::info

PopKnomi should normally be updated over OTA. Use this method only when the OTA update is unavailable.

:::

- If the CH340 driver is not installed on your computer, download and install [CH341SER.EXE](https://www.wch.cn/downloads/CH341SER_EXE.html).

- Download the [Flash Download Tool](https://www.espressif.com/zh-hans/support/download/other-tools).

- Download the [PopKnomi firmware](https://github.com/bigtreetech/PopKnomi).

- Press and hold the `Boot` button on PopKnomi, then connect it to your computer using Type-C. A new COM port should appear in Device Manager.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-boot.webp').default} width="30%"/>

- Open `flash_download_tool_3.9.8_6.exe` and configure the dialog as shown below.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-open-esp-tool.webp').default} width="30%"/>

- Configure the flashing tool as shown below.

    <ImageView src={require('@site/docs/more-series/pop-module/popknomi/img/popknomi-set-esp-tool.webp').default} width="30%"/>

    1. Set the flash address for each .bin file and select all preceding checkboxes.

        - Write `pop_knomi_bootloader.bin` to `0x1000`.

        - Write `pop_knomi_partitions.bin` to `0x8000`.

        - Write `pop_knomi_01.00.00.01.bin` to `0x10000`.

        - Write `pop_knomi_01.00.00.01.img` to `0x910000`.

    2. Set the COM port to the PopKnomi port shown in `Device Manager` -> `Ports`, then select an appropriate baud rate. We recommend `460800`.

    3. Tap `START` to begin flashing. Wait for flashing to complete, then disconnect and restart the device.
