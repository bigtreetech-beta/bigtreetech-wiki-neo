## Product Introduction

**PopStation mini** is a purpose-built mobile workstation for the Snapmaker U1, combining moisture-protected filament storage, automatic feeding, filament drying support, and real-time printer status display in one integrated setup.

- **Filament Storage and Moisture Protection**: The fully enclosed, sealed design helps block humid air and keeps filament dry.
- **Standard Rubber Feet, Optional Leveling Casters**: Rubber feet provide stable support, while optional leveling casters make the setup easier to move.
- **Compatible with Panda Breath**: Print While It Dries. Filament stays dry inside the station and feeds directly to the printer.
- **PC Viewing Window**: The heat-resistant PC window provides a clear view of the remaining filament.
- **Compatible with Panda RGB Controller**: Once bound to the Snapmaker U1, the controller displays printer status in real time while adding customizable RGB lighting beneath the station, making print status easier to monitor and your setup more visually distinctive.
- **Durable Sheet-Metal Construction**: The whole frame is bent from a single sheet of metal and laser-welded at the joints — tight, rigid, and built to last.
- **Space-Saving Design**: Moves filament storage beneath the Snapmaker U1 to free up valuable desktop space.

Power on the Snapmaker U1, go to Settings, and complete the following three steps.

Connect to the hotspot, and record the IP address after the connection is successful.

Still under "Maintenance", tap "Root Access", scroll through all the content, then accept the prompt and enable it.

<ImageView src={require("@site/docs/more-series/pop-module/popstation-mini/img/popstation-mini-installation-29.webp").default} width="40%" />

Turn on your computer and connect to the same Wi-Fi network as the Snapmaker U1. Open a terminal. Enter: **ssh root@192.168.1.156** and press Enter.(replacing this with the wifi IP address shown on your U1),then press Enter. If this is your first time connecting,type"yes" when prompted.This will not be required on future attempts. Then enter the password: **snapmaker** and press Enter to enter root mode.

:::info[Note]

Note: Replace 192.168.1.156 with the actual Wi-Fi IP address shown on your printer.

:::

<ImageView src={require("@site/docs/more-series/pop-module/popstation-mini/img/popstation-mini-installation-30.webp").default} width="80%" />

After entering root mode, enter: **touch /oem/.debug** and press Enter. This command saves modified file data permanently. Without this step, the U1 must be reconfigured each time it is powered on.

<ImageView src={require("@site/docs/more-series/pop-module/popstation-mini/img/popstation-mini-installation-31.webp").default} width="80%" />

Then, enter: **vi /home/lava/klipper/klippy/extras/filament_feed.py** and press Enter. Press the **Down Arrow** key until you reach line 504 and locate the **maxval** parameter. Press **a** to enter edit mode, then change the parameter value from 1500 to 2500. Press **ESC** to exit edit mode, enter (:wq), and press Enter.

## FAQ

### Q1: A filament tangle error appears after powering on and feeding filament?

**Solution:**

- Check each filament feed path one by one to identify the affected channel.
- Carefully check the position of the filament end in the affected feed path.
- If the filament has exited the feeder but is not visible behind the PopStation mini 4-way fitting, the PTFE tube for that channel may not be fully inserted. Remove and reinsert it securely. Also check whether the end of the PTFE tube is cut square. If it is angled, use a filament cutter to trim it flat.
- If the filament has exited the PopStation mini 4-way fitting but is not visible in the Snapmaker U1 feed tube, check that the PTFE tube is fully inserted into the Snapmaker U1 and repeat the same inspection steps.

### Q2: The feeder is connected with the 15-pin ribbon cable and the Snapmaker U1 is powered on, but the feeder does not feed after filament is inserted?

**Solution:**

- Remove the feeder that is not feeding and connect it directly to the feeder connector on the Snapmaker U1 body.
- Power the Snapmaker U1 off, then turn it back on.
- Insert filament into the feed path of that feeder and check whether it feeds normally. If there is no response, the feeder itself or the ribbon cable may be faulty. Contact Snapmaker U1 support for assistance. If it responds and feeds normally, continue checking the ribbon cables and adapters used by PopStation mini one by one.
- Reconnect **all ribbon cable connectors** once. A loose connector may cause a power supply issue. The ribbon cable connectors inside PopStation mini can be difficult to unplug, so you can remove the adapter board first and then reconnect them for testing.
- Try reconnecting the cables. If there is still no response, check each adapter and cable one by one to identify the faulty component. After locating the issue, contact after-sales support.
- Every PopStation mini undergoes a complete electrical self-test before shipment and is shipped only after passing. However, unexpected issues may still occur during transportation. If you encounter a problem, contact after-sales support promptly.

### Q3: The feeder works normally, but feeding stops before the filament reaches the printhead?

**Solution:**

- Check whether you forgot to enter the command: touch /oem/.debug. Refer to the setup steps above.
- Check the **filament_feed** parameters in the Snapmaker U1 settings and configuration file. Make sure the **preload_length** parameter is set to 2000 and saved.

### Q4: Panda RGB Controller Wi-Fi connection fails or remains on "Connecting"?

**Solution:**

- Make sure the Wi-Fi password is correct.
- Make sure the router supports 2.4 GHz Wi-Fi. 5 GHz-only Wi-Fi networks are not supported.
- If connection fails repeatedly, try restoring factory settings and configuring the device again.

### Q5: Panda RGB Controller cannot find the printer during scanning?

**Solution:**

- Make sure the printer is powered on and connected to the network.
- Make sure the Panda RGB Controller and printer are on the **same local network**.

### Q6: Panda RGB Controller settings are lost after a restart?

**Solution:**

- Make sure you tapped the **Save Settings** button after making changes.

### Q7: How do I restore factory settings?

1. Go to the **Settings** page.
2. Tap the **Factory Reset (Restore Factory Settings)** button.
3. Confirm. The device will restart automatically and clear all settings.

> Factory reset clears all settings (Wi-Fi, printer binding, parameter settings, etc.), so proceed with caution!

### Q8: How do I access the Web UI using the hostname?

The default hostname is `PandaRGBController`. Enter the following in a browser:

```
http://PandaRGBController.local
```

If the page cannot be accessed, check the device IP address on the **Wi-Fi & IP** page and access it directly using the IP address.
