## Product Overview

The Panda Exoskeleton is a modular mounting platform designed for Bambu Lab P/X series printers. Its lightweight metal construction and quick-release mounting system support the AMS, AMS 2 Pro, and compatible modular accessories. The sturdy frame provides a stable mounting solution, while the flip-back design allows convenient access to the printer.

## Technical Specifications

| Specification       | Panda Exoskeleton      |
| -------------- | -------------------- |
| Materials       | 6061 aluminum alloy and steel        |
| Color     | Matte black           |
| Compatible Printers | Bambu Lab P1/X1/P2        |
| Weight       | 1.2 kg                 |

## Installation Guide

### Remove Rear Screws

    Remove the screws highlighted in the image. Keep them handy for future reinstallation.

        <ImageView src={require('@site/docs/panda-series/module/panda-exoskeleton/img/panda-exoskeleton-dismantle.webp').default} alt="" width="90%" />

### Install the Main Body

    Align the Panda Exoskeleton main body with the mounting holes exposed in the previous step. Secure the main body using the supplied M3 x 12 socket head cap screws. Check that the main body is firmly attached before proceeding.

        <ImageView src={require('@site/docs/panda-series/module/panda-exoskeleton/img/panda-exoskeleton-install.webp').default} alt="" width="45%" />

        <ImageView src={require('@site/docs/panda-series/module/panda-exoskeleton/img/panda-exoskeleton-install-1.webp').default} alt="" width="45%" />

:::tip

The main body is interchangeable between the left and right sides. For P2S installation, leave the screw to the left of the filament inlet in place.

:::

### Install the Top Module and Printed Parts [Download Print Files](https://makerworld.com/zh/models/3461321-panda-exoskeleton-print#profileId-3949686)

    1. Insert the Top Module. Slide it into the quick-release mount until securely seated.

    2. Attach the matching 3D-printed brackets to the bottom of the AMS using M3 x 15 pointed-tip screws.

    3. Center the AMS. Position it relative to the mounting frame.

    4. Secure the printed brackets to the Top Module using four M3 x 15 machine screws.

    5. Raise the AMS until it reaches its mechanical stop, then secure the 3D-printed parts using six M3 x 15 self-tapping screws.

:::tip

The 3D-printed brackets are side-specific. Download and print the correct left- and right-hand parts for your AMS model before installation. Do not interchange the two sides.

:::

### Install Front Foot Supports

    After installing the Top Module, flip the AMS.

    Insert the matching 3D-printed front foot supports into the bottom of the AMS, then attach the rubber pads to the underside of each support to protect the printer's glass top panel from scratches.

        <ImageView src={require('@site/docs/panda-series/module/panda-exoskeleton/img/panda-exoskeleton-install-ams-1.webp').default} alt="" width="90%" />

### Install Safety Pin Holder

    Attach the printed safety pin holder to the mounting holes on the side of the Panda Exoskeleton main body using two M3 x 12 machine screws.

    To secure the AMS in the flipped-up position, insert the safety pin through the two aligned holes.

:::tip

Remove the safety pin before lowering the AMS. Lowering the assembly with the pin inserted may damage the mechanism.

:::

## Quick-Release Operation

    To remove the Top Module, support the module, press and hold the release button, then lift it out. To reinstall: Align the module, push it down until the lock engages, and check that it is secure.

## Modular Add-Ons

### Install Low-Friction Spool Holders

    1. Assemble the 3D-printed components according to the illustrations. [Download 3D Models](https://makerworld.com/zh/models/3461321-panda-exoskeleton-print#profileId-3949686). Insert the assembled spool holders into the quick-release mounts on the Panda Exoskeleton main body, ensuring the left and right holders are installed on the correct sides. Confirm that both holders are seated securely before placing spools on them.
