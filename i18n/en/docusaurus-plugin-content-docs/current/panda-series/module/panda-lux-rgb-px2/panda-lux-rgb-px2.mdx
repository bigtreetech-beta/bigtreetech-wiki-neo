## Introduction

Panda Lux RGB PX2 is a dual RGB light-bar kit for Bambu Lab P2S and X2D printers. It uses the same controller platform, firmware, and operating workflow as Panda Lux RGB PX, with PX2-specific mounting, two light bars, and the Panda Hub PX2 power module.

## Feature Highlights

- **Dual Light Bars:** Provides left- and right-side RGB lighting.
- **Printer Synchronization:** Can follow the printer's stock-light on/off state.
- **Lighting Effects:** Includes Static, Breathing, Strobing, Wave, Marquee, Color Cycle, Rainbow, Warning: Hot, and H2D Style Status Indicator modes.
- **Web Control:** Adjusts the effect, color, brightness, and speed from the controller Web UI.
- **Maintenance:** Supports firmware OTA updates and factory reset from the Settings page.

| --- | --- |

| Controller | Same controller platform as Panda Lux RGB PX |
| Firmware / Web UI | Same firmware and operating workflow as Panda Lux RGB PX |
| Power Module | Panda Hub PX2 |
