## 简介

Panda Lux RGB PX2 是一款适用于 Bambu Lab P2S 和 X2D 打印机的双 RGB 灯条套件。它采用与 Panda Lux RGB PX 相同的控制器平台，固件和操作流程，并针对 PX2 采用专用安装结构，双灯条设计以及 Panda Hub PX2 供电模块。

## 功能亮点

- **双灯条：** 提供左右两侧 RGB 照明。
- **打印机同步：** 可跟随打印机原装照明的开关状态。
- **灯光效果：** 包含 Static，Breathing，Strobing，Wave，Marquee，Color Cycle，Rainbow，Warning: Hot 和 H2D Style Status Indicator 模式。
- **Web 控制：** 可通过控制器 Web UI 调节灯光效果，颜色，亮度和速度。
- **维护：** 支持在 Settings 页面进行固件 OTA 更新和恢复出厂设置。

## 支持配置

| 项目 | 规格 |
| --- | --- |
| 支持的打印机 | Bambu Lab P2S 和 X2D |
| 灯条 | 两根 RGB 灯条 |
| 控制器 | 与 Panda Lux RGB PX 使用相同的控制器平台 |
| 固件 / Web UI | 与 Panda Lux RGB PX 使用相同的固件和操作流程 |
| 供电模块 | Panda Hub PX2 |
| 安装方式 | PX2 专用打印件安装座，磁吸灯条安装方式以及线材走线结构 |
