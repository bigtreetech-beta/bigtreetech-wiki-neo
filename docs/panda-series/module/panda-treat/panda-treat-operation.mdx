# Panda Treat 操作

:::info[Note]

本节假定你已经按照硬件部分提供的说明，将 Panda Treat 组装并安装到打印机上。

:::

## 首次设置

安装 Panda Treat 并打开打印机后，Panda Treat 会显示用于首次设置的 QR code。

<ImageView src={require('./img/factory-reset-lcd-pixel-circle.webp').default} width="15%"/>

使用手机或电脑扫描 QR code，连接到 Panda Treat 在设置过程中创建的 WiFi hotspot。扫描 QR code 后，可能需要点击弹窗才能让设备执行该操作。连接到 Panda Treat hotspot 最多可能需要 30 秒，并且你可能需要打开设备上的浏览器，以提示设备自动跳转到 Panda Treat 设置页面。

设置过程中，浏览器可能会显示 `No internet connection`；这是正常现象，因为设备是直接连接到 Panda Treat access point。设置页面加载后，应如下面图片所示。如果扫描 QR code 后 60 秒内仍未加载，你可以直接在浏览器中输入 `192.168.254.1` 并按 Enter 访问配置页面。

<ImageView src={require('./img/captive-portal.webp').default} width="30%"/>

选择首选语言并选择 `下一步`。在 WiFi 页面选择 `扫描`，扫描完成后选择与打印机相同的本地 WiFi 网络，输入 WiFi 密码，然后选择 `连接`。

<ImageView src={require('./img/wifi-selection.webp').default} width="30%"/>

Panda Treat 连接到所选网络时，请保持浏览器页面打开。如果你误关页面，或与 Panda Treat hotspot 断开连接，可以再次扫描屏幕上的 QR code 回到 WiFi 设置页面。连接成功后，选择 `绑定打印机` 继续进入打印机绑定页面；如果需要停留在 WiFi 和 IP 页面，则选择 `取消`。

<ImageView src={require('./img/wifi-connected-binding.webp').default} width="50%"/>

在 `绑定打印机` 页面选择 `扫描` 搜索可用打印机。扫描最多可能需要 60 秒。列表中出现打印机后，选择已安装 Panda Treat 的那台打印机。如果找不到打印机，请检查 Panda Treat 是否与打印机处于同一 WiFi 网络，并确认打印机已开机。不建议使用访客网络，因为它们通常会阻止设备之间通信。

如果以上条件都满足但仍找不到打印机，则需要手动输入详细信息。按照下图所示，在打印机设置页面中查找并输入打印机序列号 (SN)，access code 和 printer IP。

<ImageView src={require('./img/find-access-code.webp').default} width="70%"/>

<ImageView src={require('./img/binding-to-printer.webp').default} width="70%"/>

确认打印机信息正确后，选择 `绑定`。当出现 `绑定成功` 时，Panda Treat 已绑定到指定打印机。随后，Panda Treat 显示屏会根据打印机状态显示动画。

<ImageView src={require('./img/bound-to-printer.webp').default} width="50%"/>

WiFi 和打印机绑定完成后，在同一网络中的设备上使用 `pandatreat.local` 进行正常的 Panda Treat 操作。

### 将 Panda Treat 添加到主屏幕

为了获得最可靠的快捷方式，请先使用稳定的 `.local` 地址打开 Panda Treat，例如 `http://pandatreat.local`。与数字 IP 地址不同，路由器为 Panda Treat 分配新的 IP 地址后，这个地址通常仍可继续使用。

打开汉堡菜单并选择 `添加到主屏幕`。当 Panda Treat 尚未从主屏幕图标运行时，受支持的 iPhone，iPad 和 Android 浏览器会显示此菜单项；桌面电脑不会显示。

<ImageView
    src={require('./img/panda-treat-add-to-home-screen-menu.webp').default}
    alt="Panda Treat 汉堡菜单，其中设置与关于之间显示添加到主屏幕选项"
    width="40%"
/>

打开汉堡菜单并选择 `添加到主屏幕`。

如果你是通过 IP 地址打开 Panda Treat，指南会要求选择 `打开 .local 地址`。Panda Treat 随后会打开稳定地址，并自动再次显示指南。

<ImageView
    src={require('./img/panda-treat-home-screen-local-address-guide.webp').default}
    alt="Panda Treat 主屏幕指南提示用户打开稳定的 local 地址"
    width="40%"
/>

出现提示时，选择 `打开 .local 地址`，通过 Panda Treat 的稳定地址继续操作。

#### iPhone 或 iPad

1. 在 Safari 或 Chrome 中轻点浏览器的 `共享` 按钮。
2. 选择 `添加到主屏幕`。
3. 确认名称为 `Panda Treat`，然后轻点 `添加`。

#### Android 手机或平板电脑

如果 Panda Treat 显示 `安装应用` 按钮，请选择它并确认浏览器提示。如果没有显示该按钮，请打开 Chrome 的三点菜单，选择 `添加到主屏幕`，并在出现 `安装应用` 时选择它。否则请选择 `创建快捷方式`，然后确认 `添加`。其他 Android 浏览器的菜单措辞可能不同。

浏览器支持时，`安装应用` 会在类似应用的独立窗口中打开 Panda Treat。`创建快捷方式` 同样可以快速访问，但可能会在普通浏览器标签页中打开。

#### 如果主屏幕图标无法打开

1. 确认 Panda Treat 已开机。
2. 确认手机或平板电脑与 Panda Treat 连接到同一个 WiFi 网络。
3. 如有需要，将手机或平板电脑直接连接到 Panda Treat 自己的 WiFi 网络。
4. 打开浏览器并访问 `http://192.168.254.1`。
5. 如果更改过 Panda Treat 主机名，请删除旧的主屏幕图标，打开新的 `.local` 地址，然后重新添加图标。

删除主屏幕图标不会清除任何 Panda Treat 设置。

## 软件更新

Panda Treat 会不定期收到软件更新，这些更新会为产品增加常规改进，并可能启用额外功能。强烈建议定期检查软件更新，尤其是在首次设置完成后立即检查。

检查软件更新最简单的方法是让 Panda Treat 自动检查。只要它连接到具有互联网连接的 WiFi 网络，就会自动执行检查。如果有可用更新，显示屏会显示如下图所示的图像。使用与 Panda Treat 位于同一 WiFi 网络的设备扫描 QR code，它会带你进入可安装更新的页面。

<ImageView src={require('./img/update-rounded.webp').default} width="15%"/>

你也可以点击右上角 hamburger menu 中的设置选项，手动访问该页面。

<ImageView src={require('./img/access-settings-menu.webp').default} width="70%"/>

页面加载后，应出现一个弹窗，提示有可用更新。选择 `确认` 继续更新。更新过程中，Panda Treat 应保持连接互联网，并且不要断开电源。更新通常分两个阶段进行，进度会通过 Web UI 以及 Panda Treat 显示屏显示。

<ImageView src={require('./img/update-available-popup.webp').default} width="40%"/>

如果 Panda Treat 未连接互联网，仍可手动下载并安装更新文件。要手动应用更新，请先从 [CMYLabs/PandaTreat releases](https://github.com/CMYLabs/PandaTreat/releases) 下载最新软件。

之后，进入设置菜单并选择 `手动更新`。固件更新请选择文件名中包含 `firmware` 的文件；用户界面更新请选择文件名中包含 `UI` 的文件。

<ImageView src={require('./img/manual-update.webp').default} width="70%"/>

更新安装完成后，Panda Treat 会重启并重新连接到 WiFi 网络。

## 设置

Panda Treat 设置涵盖网络访问，打印机绑定，语言和单位，软件更新，待机显示图像，打印间距以及恢复功能。

在打印界面右上角打开汉堡菜单并选择 `设置`。设置站点打开后，在导航中再次选择 `设置`。手机和平板电脑的标签位于右下角，桌面页面的选项位于左侧导航栏。下图展示了这两个步骤。

<ImageView src={require('./img/access-settings-menu.webp').default} width="70%"/>

### WiFi 和网络

打开 `Wi-Fi 和网络` 可查看 Panda Treat 正在使用的网络，复制当前 IP 地址，或查看并更改稳定主机名。书签和主屏幕图标应优先使用页面显示的 `.local` 地址，因为数字 IP 地址变化后它仍可继续使用。

如果 Panda Treat 需要加入其他网络，请使用 `Wi-Fi 网络配置`。更改连接时请保持页面打开。手机或电脑可能会暂时与 Panda Treat 断开，并且可能需要先加入新网络才能再次打开页面。

`Panda Treat 热点` 用于管理 Panda Treat 创建的专用 WiFi 网络。你可以让热点保持开启，更改名称或密码，以及更改直接连接 IP 地址。通过该热点访问页面时更改这些项目，当前设备可能会断开连接。选择 `保存热点设置` 前请仔细检查；使用 `放弃更改` 可恢复 Panda Treat 最近显示的值。

### 打印机连接

打开 `绑定打印机` 可查看或更改已连接的打印机。选择 `扫描` 并等待搜索完成，然后从列表中选择受支持的打印机。如果没有找到打印机，请手动输入序列号，访问码和打印机 IP。

已经绑定打印机时，它仍会在列表中保持选中，操作按钮显示为 `解绑`。你仍可选择另一台打印机。新打印机具有受支持的型号以及有效的序列号，访问码和 IP 地址后，操作按钮会变为 `绑定`。选择后，旧绑定会被新绑定替换。

### 语言，单位以及返回打印界面

使用 `语言和单位` 中的 `界面语言` 在英语和简体中文之间切换，并使用 `尺寸单位` 选择毫米或英寸。选择导航中的 `犒劳自己` 可返回主打印界面。

### 待机显示图像

`待机显示图像` 控制 Panda Treat 屏幕在待机时显示的图像。默认使用内置熊猫图像。

- 选择 `更改图像`，然后选择此浏览器支持的静态 JPEG，PNG，WebP，HEIC 或 HEIF 图像。不支持 GIF 和动态图像。
- 拖动图像可调整位置。使用双指捏合，鼠标滚轮或缩放滑块可调整大小。圆形遮罩显示图像在圆形屏幕上的可见范围。
- 选择 `安装图像` 后，请保持页面打开并勿移除 SD 卡，直到保存和验证完成。
- 如需重新使用内置熊猫图像，请选择 `恢复默认图像`，然后确认恢复。

### 更新和打印间距

固件与用户界面版本，在线检查更新以及手动更新已在[软件更新](#软件更新)中介绍。

`墨条间距` 用于更改相邻打印走线之间的距离：

- 选择 `恢复默认值` 可恢复为 `8.40`。
- 如果深色条带发生重叠，请将数值增加 `0.01`。
- 如果出现浅色或白色间隙，请将数值减少 `0.01`。
- 如果多次小幅调整都没有改善，请恢复 `8.40`，因为问题很可能不是由墨条间距引起。

更改后选择 `保存调整`。调整此设置前，应先清洁并检查墨盒。

### 安全和恢复出厂设置

正常使用时应保持 `急停保护` 启用。禁用后，Panda Treat 将无法按正常方式请求打印机立即停止。对于未使用 LAN Developer Mode 的打印机，Panda Treat 会改为发出蜂鸣警告并显示停止提示；整个过程可能额外增加约八秒。只有特定诊断流程明确要求时才应禁用此功能。

`将 Panda Treat 恢复出厂设置` 会清除已保存的 WiFi 网络，打印机绑定信息以及 Panda Treat 首选项。只有确实准备从头重新设置产品时才应使用。

## 在物品上打印

### 所需内容

使用 Panda Treat 时，你会打印到具有特定宽度，长度和高度的物品上。你需要告诉 Panda Treat 这些测量值。

要测量物体的宽度，长度和/或直径，可以使用简单的尺子，也可以使用游标卡尺等更复杂但更准确的工具。你也可以使用下方链接打印自己的游标卡尺。

测量高度时，建议使用下方所示的可打印工具。该工具的摆臂可以扫过你计划打印的物体，从而检查表面一致性，并确保没有可能刮碰的高点。

<ImageView src={require('./img/measure-object.webp').default} width="50%"/>

- Printable height measurement tool with instructions - Coming soon
- Printable vernier callipers: [vernier-caliper-ruler-two-lengths](https://makerworld.com/en/models/198362-vernier-caliper-ruler-two-lengths)

### 准备打印表面并打开 Panda Treat

准备任何打印任务前，请在打印机成型板范围内铺好干净，食品安全的硅胶烘焙垫或烘焙纸。垫子或烘焙纸必须保持平整，并完全位于成型板边界内。

<ImageView src={require('./img/prepared-surface.webp').default} width="45%"/>

扫描 Panda Treat 显示屏上的 QR code，或打开之前保存的 `.local` 地址，进入 Panda Treat 打印界面。手机，平板电脑或电脑必须与 Panda Treat 位于同一 WiFi 网络。

:::info[Note]

为了以后更快打开，可以将 `.local` 地址加入书签，或按照[将 Panda Treat 添加到主屏幕](#将-panda-treat-添加到主屏幕)中的步骤创建图标。

:::

<ImageView src={require('./img/qr-to-print-page.webp').default} width="70%"/>

首页提供 `饼干 / 蛋糕`，`饮品` 和 `故障排查`。下面分别介绍两种打印流程。

<ImageView src={require('./img/item-type-selection.webp').default} width="70%"/>

### 饼干 / 蛋糕流程

此流程适用于饼干，蛋糕以及其他顶部可打印的固体物品。

1. 在首页选择 `饼干 / 蛋糕`。
2. 在 `形状` 中选择 `方形` 或 `圆形`，使其与物品外形匹配。如果是不规则饼干，请使用[自定义形状准备工作流](#自定义形状准备工作流)。
3. 在 `网格` 中选择列数和行数。第一次打印建议保留 `1 x 1`。批量打印时可增加行数或列数，并选择 `预览网格` 检查间距和物品最大尺寸。
4. 在 `尺寸` 中输入物品完整的宽度，长度和最高点。即使图稿只覆盖较小区域，也应测量整个物品，这样更容易将物品放进打印出的标记内。如果可打印区域需要避开物品外边缘，请使用 `内缩边框`。

:::warning[测量最高点]

高度不正确可能导致打印头拖过物品。如果表面不平整，请在测量高度上增加 1 mm。

:::

5. 在 `图稿` 中点击预览区域或 `更换图片`，选择要打印的图片。拖动图片进行定位，并使用滑块或双指手势调整缩放。红色轮廓表示测量后的物品外形，蓝色内缩线表示可选的内缩边框。
6. 需要无障碍查看图稿时选择 `隐藏标记`，需要恢复参考线时选择 `显示标记`。`重新居中` 只会清除图片移动量，并保留当前缩放。`全部重置` 会让图片回到中心和 100% 缩放；不会更改形状，网格或尺寸。

<ImageView src={require('./img/print-workflow-a-to-e.webp').default} width="70%"/>

7. 在 `发送` 中选择适合当前任务的打印选项：
    - `草稿模式` 会准备速度更快的预览质量打印。
    - 只有受支持的打印机才会显示 `高墨量模式`。它会喷涂更多食用墨水，可用于普通打印颜色过浅的情况。
    - `设为收藏` 会用你提供的名称保留该打印任务，避免被下一次发送的打印任务替换。请输入 3 到 18 个受支持的字符。只要继续使用相同的 SD 卡，收藏任务就会保持可用。
8. 需要放置参考时，选择 `将标记文件发送到机器`。标记会直接打印到食品安全表面上，显示每件物品的放置位置。
9. 选择 `将图像文件发送到机器` 以发送全彩图稿。如果已经有可靠的物品定位方式，可以不发送标记文件。

设置尚未完成时，发送操作仍会显示，但外观会变淡。选择被阻止的操作后，页面会短暂显示具体缺少的项目。选择其中任一原因即可返回需要补充的图稿或尺寸。只有图稿，宽度和长度全部有效后，Panda Treat 才会准备文件。

<ImageView src={require('./img/print-workflow-f-to-g.webp').default} width="70%"/>

确认任一发送操作后，请保持页面打开，等待 Panda Treat 完成文件准备和上传。

<ImageView src={require('./img/uploading-print.webp').default} width="35%"/>

### 饮品流程

此流程用于将图稿打印到平滑，稳定的饮品表面，例如拿铁或啤酒泡沫。请在即将打印时再准备饮品，避免打印机设置期间泡沫塌陷。

1. 在首页选择 `饮品`。
2. 在 `形状` 中选择 `圆形` 或 `方形`，使其与可用顶部表面匹配。
3. 在 `网格` 中选择要放在打印表面上的饮品数量。建议先使用 `1 x 1`；批量打印前请选择 `预览网格`。
4. 测量泡沫可用表面的完整宽度和长度。高度应从食品安全表面量到泡沫最高可打印位置，并包含杯子或玻璃杯本身。将这些数值输入 `尺寸`。
5. 如果 Panda Treat 提示饮品高度较低，请重新测量。只有当输入值确实是从食品安全表面到泡沫表面的距离时才继续。
6. 在 `图稿` 中点击预览区域或 `更换图片`，然后定位并缩放图片。重要细节应避开不平整，气泡较多或靠近杯沿的泡沫。
7. 需要时，可按照饼干 / 蛋糕流程使用 `草稿模式`，受支持打印机显示的 `高墨量模式` 或 `设为收藏`。
8. 在成型板上没有饮品时发送并打印标记文件。标记会显示杯子或玻璃杯的放置位置。
9. 将饮品稳固放入标记内，不要移动食品安全表面。确认容器稳定，泡沫仍然平滑，并且任何部分都不会碰到移动的打印头。
10. 发送图像文件，然后继续下方的[打印工作流](#打印工作流)。

### 自定义形状准备工作流

当饼干外形不是简单的圆形或方形时，请使用此工作流。你可以让 Panda Treat 从图片中识别外轮廓，也可以使用 Cookiecad 创建更复杂的模具。

无论选择哪种方式，都先完成以下操作：

1. 在打印机成型板范围内铺好食品安全的硅胶烘焙垫或烘焙纸。
2. 确认操作设备与 Panda Treat 位于同一 WiFi 网络，然后扫描 Panda Treat 显示屏上的 QR code，或打开之前保存的 Panda Treat 页面。
3. 在首页选择 `饼干 / 蛋糕`，然后在 `形状` 步骤选择 `自定义`。
4. 在弹出的窗口中选择 `Panda Treat 流程` 或 `Cookiecad 流程`。

<ImageView src={require('./img/panda-treat-custom-workflow-chooser.webp').default} width="70%"/>

#### Panda Treat 流程

如果图片中的物体具有清晰，连续的外轮廓，并且背景简单，请使用此流程。Panda Treat 会从图片中找到主要物体，并让饼干模具，放置标记和最终打印图案保持匹配。

1. 选择 `Panda Treat 流程`。
2. 在 `网格` 步骤选择一次要打印的饼干数量。第一次使用时，建议保留 `1 x 1`。如果要一次打印多块饼干，请增加行数或列数，然后选择 `预览网格` 检查布局。如果 Panda Treat 显示较小的最大值，请使用它允许的值。
3. 点击图稿预览区域或 `更换图片`，选择要印在饼干上的图片。效果最好的是背景颜色均匀，只包含一个主要物体且完整外边缘清晰可见的图片。尽量避免杂乱背景和明显阴影。
4. 等待 Panda Treat 处理图片。红色线条应沿着物体完整的外边缘，既不能包住不需要的背景，也不能切进物体本身。请逐步调节 `背景灵敏度`，使用能够去除多余背景，同时保留完整物体的最低数值。可以选择 `隐藏标记` 暂时隐藏红线检查图稿，再选择 `显示标记` 恢复红线。

下面的橄榄球展示了为什么需要仔细调整。数值为 `17` 时，红线能完整，干净地沿着橄榄球外缘：

<ImageView
    src={require('./img/panda-treat-custom-background-sensitivity-17.webp').default}
    alt="Panda Treat 自定义形状编辑器在背景灵敏度 17 时显示完整的橄榄球轮廓"
    width="70%"
/>

背景灵敏度 17 保留了完整橄榄球，包括两端的浅色条纹。

数值为 `48` 时，灵敏度对浅色区域过高。部分白色条纹和上方边缘被当成背景，因此红线切进了橄榄球：

<ImageView
    src={require('./img/panda-treat-custom-background-sensitivity-48.webp').default}
    alt="Panda Treat 自定义形状编辑器在背景灵敏度 48 时，轮廓切入橄榄球浅色区域"
    width="70%"
/>

背景灵敏度 48 去掉了物体的一部分，不适合这张图片。

如果较低数值仍然包住一些背景，请每次只把滑块向上移动一点。背景刚好消失时就应停止；如果红线开始切进物体，请把滑块调低。

Panda Treat 自定义形状编辑器中的 `重新居中` 处于不可用状态，因为检测到的轮廓必须与图稿保持对齐。`全部重置` 只会将 `背景灵敏度` 恢复为默认值；不会清除图片，尺寸，网格或检测到的形状。

5. 在 `尺寸` 步骤输入计划制作的饼干宽度或长度。Panda Treat 会根据检测到的形状自动调整另一项尺寸，因此宽度和长度不能分别拉伸。自定义形状不使用内缩边框。
6. 再次检查网格和尺寸。如果出现尺寸警告，请减少网格数量或缩小饼干，直到警告消失。
7. 选择 `创建模具`。模具准备完成后，可以拖动 3D 预览来旋转，并使用滚轮缩放。确认外形正确，然后选择 `下载 STL`。STL 是供 3D 打印机使用的模具模型文件。无需手动镜像图片；下载的模具已经为翻转后压入面团的使用方式做好了方向处理。

如果 Panda Treat 无法制作模具，请尝试使用外轮廓更简单，背景更干净的图片。

:::tip[此时可以暂停]

下载 STL 后，你可以暂停 Panda Treat 流程，3D 打印模具，用它切出并烘烤饼干，等饼干准备好后再回来继续。

请关闭模具预览，但保持当前 Panda Treat 标签页打开，不要刷新页面，也不要点击离开此页面。当前自定义设置不会保存为可重新打开的项目。如果浏览器刷新或关闭了该标签页，你需要使用相同图片和设置重新完成自定义形状步骤。建议同时记下尺寸和 `背景灵敏度`，或截一张图作为备份。

:::

8. 饼干烘烤并冷却后，返回保持打开的 Panda Treat 页面。测量实际饼干最高点，并在 `点心高度` 中输入该高度。如果表面不平整，请在测量值上增加 1 mm。
9. 最后检查红色轮廓，尺寸和网格预览，确保它们与已经烤好的饼干一致。

#### Cookiecad 流程

如果需要的模具比 Panda Treat 能从简单图片中识别的外形更复杂，请使用此流程。你需要互联网连接和 Cookiecad 帐户。Cookiecad 设计器会在 Panda Treat 页面内打开。

1. 选择 `Cookiecad 流程`，并在 Cookiecad 提示时登录或创建帐户。
2. 在 Cookiecad 中选择一个现有形状，或上传自己的图片。使用图片时，请尽量选择主要形状清晰，外边缘完整的图案；过小的细节可能很难 3D 打印，也可能无法在面团上清楚成形。
3. 设置成品模具的实际尺寸。Cookiecad 返回的宽度和长度将成为 Panda Treat 中使用的饼干尺寸，因此应在继续前确认大小正确。
4. 检查外轮廓和任何需要切出的内部孔洞。Panda Treat 稍后会将彩色图稿印到饼干上，因此一般应让饼干顶部保持平整，除非你特意希望模具压出内部细节。
5. 旋转 Cookiecad 的 3D 预览，从各个角度检查模具。确认切割边缘连续，重要部分相互连接，并避免过细或孤立的细节。如果内部部分需要支撑，可以使用 Cookiecad 的 center bar 功能连接它们。
6. 对设计满意后，按照 Cookiecad 屏幕上的提示为 Panda Treat 准备并返回设计。
7. 等待设计返回 Panda Treat。Panda Treat 会接收相互匹配的图稿，外轮廓，宽度，长度和模具文件。如果出现错误，请按屏幕提示在 Cookiecad 中调整设计，然后重新导出。过小或超出打印机可打印范围的设计不会被接受。
8. 当 Panda Treat 显示 `Cookiecad 模具已就绪` 时，返回的图稿，外轮廓，宽度和长度会锁定在一起。选择 `下载 STL` 保存模具文件。

如需了解 Cookiecad 自身的设计选项，请参阅 [Cookiecad Designer features overview](https://docs.cookiecad.com/cookiecad-designer/features-overview/)。

如果在设计完成前选择 `返回 Panda Treat`，未完成的设计不会传回。之后再次选择 Cookiecad 时，将开始一个新会话。

:::tip[此时可以暂停]

下载 STL 后，你可以暂停流程，3D 打印模具，用它切出并烘烤饼干，等饼干准备好后再返回。

请保持当前 Panda Treat 标签页打开，不要刷新或离开页面。Cookiecad 返回到 Panda Treat 的设置不会保存为可重新打开的项目。如果标签页被关闭或重新加载，你需要再次从 Cookiecad 将设计返回 Panda Treat。

:::

9. 饼干烘烤并冷却后，返回 Panda Treat，测量最高点并填写 `点心高度`。如果表面不平整，请增加 1 mm。
10. 在 `网格` 步骤选择要同时打印的饼干数量，并选择 `预览网格` 检查布局。Panda Treat 会根据 Cookiecad 返回的模具尺寸限制可用的行数和列数。
11. Cookiecad 返回的宽度，长度，图稿和外轮廓不能在 Panda Treat 中单独更改。加载锁定设计后，`重新居中` 和 `全部重置` 均处于不可用状态。如需其他设计，请再次选择 `自定义`，重新打开工作流选择器，然后重新开始需要的 Panda Treat 或 Cookiecad 流程。

#### 完成并发送打印文件

无论使用哪种自定义流程，最后的发送步骤都相同：

1. 确认 `点心高度` 是烘烤后饼干的实际高度，并最后检查网格。
2. 如果希望以后从打印机再次使用此打印，可以启用 `设为收藏` 并为它命名。
3. 建议先选择 `将标记文件发送到机器`。它会在食品安全表面上显示每块饼干的准确放置位置。
4. 选择 `将图像文件发送到机器`。发送任一打印任务时，所需的准备文件都会自动包含。
5. 文件上传完成后，请继续按照下方的打印工作流操作。先在表面上没有饼干的情况下运行标记打印，再将烤好的饼干放入轮廓内，最后运行图像打印。

### 打印工作流

图像以及可选的标记文件准备好并发送到打印机后，就可以开始打印了。请按照此流程操作，以确保打印成功。

1. 使用墨盒维护和护理部分中提到的方法擦拭墨盒底部。

    <ImageView src={require('./img/wiping-cartridge.webp').default} width="50%"/>

2. 进入打印机的打印菜单，你会看到每张发送图像最多对应三种不同打印文件。

    <ImageView src={require('./img/print-files-on-printer.webp').default} width="70%"/>

    - `准备打印`：此文件会让打印机归位，并将热床移动到可以放置物体的位置。如果你在过去 15 分钟内没有准备过打印机，则在执行第一次图像打印之前必须先运行它。
    - `标记打印`：此文件会准备打印机，并在食品安全表面上打印标记，用来指示物体的放置位置。
    - `图像打印`：这是最终打印到物体上的打印文件。只有在打印机已经完成准备后才应运行它。

    :::info[Note]

    运行标记打印时，表面上绝不能放置物体，否则物体会与打印头碰撞。

    :::

3. 如果需要打印标记文件，请选择该选项，并确保右侧所有选项都处于禁用状态：选择它们，并确认任何选项周围都没有绿色轮廓。

    <ImageView src={require('./img/disable-options.webp').default} width="70%"/>

4. 如果正在打印标记文件或准备文件，请趁此机会确认打印表面上完全没有任何物体。确认后，选择打印。

    <ImageView src={require('./img/filament-review-screen.webp').default} width="70%"/>

5. 打印机会执行一些准备步骤，然后打印所选文件。如果在准备过程中任何时候听到 Panda Treat 发出响亮蜂鸣声，这是警告你尚未运行所需的准备打印文件。你应立即停止打印，并运行所需的准备文件。如果打印机尚未准备好，你会在 Panda Treat 屏幕上看到提示。

    <ImageView src={require('./img/not-prepared-rounded.webp').default} width="15%"/>

6. 如果文件成功打印，你将得到以下结果之一：

    - 打印表面上的标记。
    - 处于已准备状态的打印机。
    - 已打印图像的物体。

7. 如果刚才打印的是标记文件，那么打印表面上会出现如下所示的红色标记。

    <ImageView src={require('./img/marker-outline.webp').default} width="45%"/>

8. 如下图所示，将物体放入轮廓内。

    <ImageView src={require('./img/object-on-plate.webp').default} width="45%"/>

9. 打印图像文件，并观察点心接收打印图案。

    <ImageView src={require('./img/printed-object.webp').default} width="45%"/>

如果希望颜色更加饱和，请保持点心位置不变，并在打印机屏幕上选择 `重新打印`。

## 故障排查

Panda Treat 首页包含完整的 `故障排查` 部分，并通过图示说明常见打印质量和连接问题。下方也汇总了主要恢复步骤，便于快速查阅。

### 墨盒喷嘴堵塞

随机出现白色条纹，缺色或覆盖不均，通常表示一个或多个喷嘴出墨不顺畅。食用墨水干燥很快，因此墨盒长时间暴露时喷嘴可能堵塞。

<ImageView
    src={require('./img/panda-treat-troubleshooting-clogged-ink-nozzles.webp').default}
    alt="喷嘴堵塞时可能出现的缺色和颜色条带不均示例"
    width="50%"
/>

缺色和颜色条带不均，通常表示一个或多个喷嘴出墨不顺畅。

1. 取下墨盒，将干净纸巾折成柔软的垫状。
2. 使用快速，均匀的动作，从喷头后方向前平稳擦拭。不要左右来回摩擦。
3. 重复数次。纸巾上应清楚出现三条颜色线。
4. 重新安装墨盒并再次尝试打印。

<ImageView
    src={require('./img/panda-treat-troubleshooting-wipe-cartridge.webp').default}
    alt="演示如何从后向前擦拭墨盒喷头的动画"
    width="45%"
/>

从喷头后方向前平稳擦拭。

如果普通擦拭仍无法恢复全部三种颜色：

1. 将纸巾折好并用水打湿。纸巾只能微湿，不能滴水。
2. 将墨盒直立放置，让只有喷嘴的部分接触湿纸巾。如有需要，垫高纸巾，使其始终与喷嘴接触。
3. 保持五分钟。
4. 在湿润区域擦拭喷头数次，彻底擦干墨盒外部，然后在干燥区域从后向前擦拭。

请勿浸泡墨盒，也不要让水接触电气触点。

### 间隙与深色线条

打印走线之间规则出现白色间隙或深色条带，可能由打印机运动的细微差异引起。请先清洁墨盒，然后打开 `设置` 并找到 `墨条间距`。

<ImageView
    src={require('./img/panda-treat-troubleshooting-lines-and-streaks.webp').default}
    alt="打印走线之间出现规则浅色间隙和深色条带的示例"
    width="50%"
/>

规则的浅色间隙和深色条带，可能表示相邻打印走线没有正确衔接。

1. 确认数值为 `8.40`。如果不是，请选择 `恢复默认值`，保存设置后再次测试。
2. 如果深色条带发生重叠，请将数值增加 `0.01`，保存后测试。
3. 如果出现浅色或白色间隙，请将数值减少 `0.01`，保存后测试。
4. 只有结果持续改善时，才继续每次调整一个小步。
5. 如果多次调整都没有改善，请恢复 `8.40`；问题很可能不是由墨条间距引起。

### 墨水飞散或边缘模糊

墨水在空气中飞行时会扩散。如果打印头距离物品过高，图稿和文字边缘可能出现云雾状或模糊效果。

<ImageView
    src={require('./img/panda-treat-troubleshooting-overspray.webp').default}
    alt="墨水飞散造成图稿周围云雾状色斑和模糊边缘的示例"
    width="50%"
/>

清晰图稿周围出现云雾状颜色，是墨水飞散的典型表现。

1. 重新测量最高可打印位置，并确认输入的高度。
2. 观察打印头经过物品上方时的间隙。打印头距离目标表面不超过 `2 mm`（`0.079 in`）时，Panda Treat 的效果最佳。
3. 如果物品表面高低不平，可在适合的位置增加填充或糖霜来抬高低处。
4. 关闭附近的风扇，关闭会产生气流的窗户，或将打印机移到空气静止的位置。

切勿把间隙减小到打印头可能接触物品的程度。

### 图像异常或出现意外颜色

额外颜色，雾状痕迹，颜色极浅或随机线条，可能是墨盒与 Panda Treat 之间电气接触不良造成的。

<ImageView
    src={require('./img/panda-treat-troubleshooting-corrupted-images.webp').default}
    alt="墨盒接触不良时可能出现的意外颜色和断裂条带示例"
    width="50%"
/>

意外颜色和断裂条带可能表示墨盒电气接触不良。

1. 关闭打印机电源并取下墨盒。
2. 用干净的铅笔橡皮轻轻擦拭墨盒铜触点。
3. 检查 Panda Treat PCB 的下边缘是否完全贴合打印支架。如果存在间隙，请松开安装螺丝，均匀向下按压 PCB，然后重新拧紧螺丝。
4. 重新安装墨盒，确保铜触点与 Panda Treat 铜针牢固，均匀接触。
5. 按照上方喷嘴堵塞流程擦拭喷嘴，然后再次测试。

请勿使用金属工具刮擦铜触点，也不要用手指触摸触点。

### 墨盒存放

不使用墨盒时，请始终将它直立放入装有硅胶密封件的随附墨盒支架中。不要侧放或倒置，也不要让喷嘴暴露超过必要时间。完整的存放，密封件更换和维护说明请参阅[墨盒处理](./panda-treat-hardware#墨盒处理)。

<ImageView
    src={require('./img/panda-treat-troubleshooting-cartridge-storage.webp').default}
    alt="显示直立存放密封区域的 Panda Treat 墨盒支架"
    width="50%"
/>

将墨盒直立存放在装有硅胶密封件的支架中。

### 恢复缺失或损坏的打印界面

如果正常的饼干 / 蛋糕，饮品和故障排查首页为空白或缺失，但设置站点仍能打开，则用户界面文件可能缺失或损坏。此时固件和设置站点仍可能正常工作。

如果 Panda Treat 可以访问互联网：

1. 打开设置站点并进入 `设置和更新`。
2. 选择 `检查更新`。
3. 如果页面提供用户界面修复或更新，请确认操作，并保持 Panda Treat 通电和联网，直到更新完成。
4. Panda Treat 重启后，选择 `犒劳自己` 或重新打开其 `.local` 地址。

如果 Panda Treat 无法访问互联网：

1. 在其他设备上从 [CMYLabs/PandaTreat releases](https://github.com/CMYLabs/PandaTreat/releases) 下载兼容的 Panda Treat 版本。
2. 在设置站点中打开 `手动更新`。
3. 选择文件名标明为 **UI** 更新并以 `.bin` 结尾的文件。
4. 开始用户界面更新，并保持电源连接，直到 Panda Treat 报告完成并重启。
5. 重新打开 `.local` 地址并选择 `犒劳自己`。

固件和 UI 文件不能互换。切勿将标有 `firmware` 的文件上传到用户界面更新控件，也不要将标有 `UI` 的文件上传到固件更新控件。

### 为技术支持准备信息

完成相关故障排查步骤后问题仍然存在时，请记录：

- 打印瑕疵和墨盒触点区域的清晰照片；
- 打印机型号；
- Panda Treat 固件和用户界面版本；
- 输入的尺寸和选中的打印选项；
- 当前墨条间距数值；以及
- 已经尝试过的步骤。

这些信息能帮助技术支持更快确定原因，避免要求你重复相同检查。
