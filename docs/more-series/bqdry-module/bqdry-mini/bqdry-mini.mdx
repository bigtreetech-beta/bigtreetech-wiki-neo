# BQDry Mini

<div class="div-table">

<ImageView src={require('./img/bqdry-mini-title.webp').default}  width="45%" class="right-image"/>

## 产品简介

BQDry Mini 是一款面向 3D 打印耗材管理场景的模块化加热与烘干系统，当前以 **Bambu Lab AMS（第一代）** 为主要官方适配对象。产品由控制模块与两个加热输出模块组成，可安装在 AMS 内部，为原本没有主动加热能力的 AMS 增加主动烘干功能。

BQDry Mini 采用独立 24V 供电，在 AMS 正常供料和打印过程中也可持续工作；同时支持实体按键和 Web UI 控制，可设置烘干温度/时间，并支持与打印任务联动，实现打印开始时自动启动烘干/打印结束时自动停止。

</div>

:::warning

BQDry Mini 当前官方安装方案适用于 **Bambu Lab AMS（第一代）**，不适用于 AMS 2 Pro。其他封闭加热场景需要根据实际空间/布线/供电与热安全条件单独评估，本 Wiki 不提供通用安装保证。

:::

## 产品特点

- **AMS 内嵌式升级**：控制模块与输出模块安装在 AMS 内部，尽可能保持原有设备外观与使用方式。
- **无损安装**：无需对 AMS 外壳进行不可恢复的打孔或切割改造。
- **边烘边打**：BQDry Mini 采用独立电源，可在 AMS 正常供料和打印过程中持续烘干耗材。
- **35–60$^{\circ}\mathrm{C}$ 温度控制**：支持 35$^{\circ}\mathrm{C}$～60$^{\circ}\mathrm{C}$ 加热温度设置。
- **快捷实体控制**：支持一键启动 / 暂停 / 恢复 / 停止，并提供 4H / 8H / 12H / 24H / 不限时五档快捷时间选择。
- **Web UI 控制**：可通过浏览器完成网络配置/烘干参数设置/设备状态查看和打印机绑定。
- **可调排湿**：通过 AMS 替换把手形成可调排湿通道，帮助烘干过程中释放湿气并降低凝露风险。
- **打印任务联动**：绑定兼容打印机后，可开启"打印时启动"，在打印任务开始时自动烘干，并在打印结束后停止加热。

## AMS 安装指南

:::warning

1. 关闭打印机并断开 AMS 与打印机之间的连接线。
2. 拔下 AMS 的 PTFE 管，并将 AMS 内耗材取出。
3. 安装过程中请勿强拉 AMS 内部连接线。
4. 所有供电线和连接线必须避开 AMS 齿轮组/滚轮和线轴活动区域。
5. 建议保留拆下的 AMS 原装电源主板，以便后续恢复原始状态。

:::

打开 AMS 上盖，按住内部 PTFE 管释放装置，将 AMS 后方 PTFE 管拔出。

<ImageView src={require('./img/install01-ptfe-release.webp').default} width="35%" />
<ImageView src={require('./img/install02-ptfe-out.webp').default}  width="30%" />

<ImageView src={require('./img/install03-frame-screws.webp').default} width="45%" />

按压五通组件上的释放按钮，将主框架后部缓慢抬起。注意内部仍有线缆连接，请勿用力拉扯。

<ImageView src={require('./img/install04-release-button.webp').default} width="30%" />
<ImageView src={require('./img/install05-lift-frame.webp').default}  width="30%" />

断开 485 连接线与电源连接线，随后取出 AMS 主框架组件。

<ImageView src={require('./img/install06-disconnect-cables.webp').default}  width="50%" />

<ImageView src={require('./img/install09-3.webp').default} width="50%" />

<ImageView src={require('./img/install09-4.webp').default} width="50%" />

走线不得侵入 AMS 齿轮组或其他运动部件区域，避免使用过程中发生夹线/磨线或拉扯。

:::

使用随附的 1.5mm L 型内六角扳手拆下 AMS 原把手并安装 BQDry Mini 替换把手。

## 按键与显示

<ImageView src={require('./img/control-module.webp').default}  width="100%" />

控制模块顶部设有两个实体按键：

| 按键 / 显示 | 功能 |
| :--- | :--- |
| 时间选择按钮 | 待机时循环选择 4H / 8H / 12H / 24H / 不限时 |
| 启动 / 暂停按钮 | 待机时启动；工作时短按暂停 / 恢复；长按停止 |
| 时间档位指示灯 | 显示当前选中的快捷时间档位 |
| 工作倒计时 | 显示当前烘干剩余时间；不限时模式按固件定义显示 |
| 湿度档位 | 显示 H1～H5 环境湿度等级 |
| 加热状态指示 | 加热运行时显示工作状态 |

### 一键启动

在未选择快捷时间档位时，按下 **启动 / 暂停** 按钮，设备按照上一次 Web UI 保存的温度和时间开始加热；倒计时结束后自动停止。

加热过程中：

- 短按 **启动 / 暂停**：暂停或恢复加热，倒计时同步暂停 / 恢复。
- 长按 **启动 / 暂停**：停止本次加热。

### 快捷定时烘干

待机状态下按 **时间选择** 按钮，可在以下五档间循环切换：

`4H → 8H → 12H → 24H → 不限时`

选中时间后按 **启动 / 暂停**，设备按照 Web UI 中设定的目标温度和当前快捷时间启动加热。

## 湿度档位说明

BQDry Mini 使用 **H1～H5** 表示当前环境的湿度状态。档位越高，表示环境越潮湿。

<ImageView src={require('./img/humidity-level-guide.webp').default}  width="75%" />

| 湿度档位 | 环境状态 | 使用建议 |
| :---: | :--- | :--- |
| H1 | 干燥 | 适合耗材存储与使用 |
| H2 | 较干 | 可正常存储与使用 |
| H3 | 偏湿 | 建议启动耗材烘干 |
| H4 | 潮湿 | 建议进行耗材烘干 |
| H5 | 高湿 | 建议尽快进行耗材烘干 |

:::warning

湿度档位仅在已绑定拓竹打印机且连接 AMS 时生效

:::

:::info

湿度档位用于反映当前环境的干湿趋势，并非精确的相对湿度百分比，也不直接代表耗材内部的实际含水量。当显示 **H3/H4 或 H5** 时，建议启动 BQDry Mini 对耗材进行烘干。

:::

## Web UI 首次连接指南

### 连接设备 AP 热点

设备上电后，在手机或电脑的 Wi-Fi 列表中连接 BQDry Mini 发出的 AP 热点：

- 热点名称：`BQDry_Mini_XXXXXXXXXX`
- 默认密码：`987654321`

### 访问 Web UI

连接 AP 后：

- 手机端可能会自动弹出 BQDry Mini Web UI；
- 也可以在浏览器中输入默认 IP：`192.168.254.1`。

:::info

热点IP(默认的热点 IP 为: 192.168.254.1, 如果您自己路由器的 IP 号段也为 192.168.254.xxx, BQDry Mini与路由器的 IP 号段相同就会产生冲突, 并且导致 BQDry Mini无法正常绑定到打印机, 请手动修改 BQDry Mini 的热点 IP 使其与路由器使用不同的 IP 号段)

:::

## 恢复出厂设置

同时长按控制模块上的两个实体按键 **5 秒以上**，可触发恢复出厂设置。

恢复出厂设置后将清除或恢复以下内容：

- Wi-Fi 网络连接信息；
- 已绑定的打印机；
- 相关设备参数和 Web UI 设置。

恢复完成后，请重新按照 [Web UI 首次连接指南](#web-ui-首次连接指南) 配置设备。

## 特别说明

### 不限时加热模式

当选择"不限时"档位时，产品仍会执行内部温控保护逻辑，但为确保安全，建议设备仅在 **可观察/可监控的环境** 中运行，避免长时间无人看管。

### 排湿与凝露

加热过程中，耗材中的水分会逐渐释放至空气中。建议根据实际烘干状态使用 AMS 替换把手打开适当排湿通道，帮助湿气排出并降低内部水汽凝结的可能。

### 高温表面

设备加热运行期间，输出模块出风口及附近区域可能处于较高温度。请勿遮挡出风口，也不要在工作期间直接触摸高温区域。

### 外壳表面纹理

BQDry Mini 外壳采用 **尼龙 + 玻璃纤维（PA-GF）** 复合材料。该材料可能呈现类似细小划痕或纤维的表面纹理，这是材料本身的正常特性，并非产品瑕疵。

### FCC 合规声明

本设备符合 FCC（美国联邦通信委员会）规则第 15 部分的要求。设备运行须满足以下两个条件：

1. 本设备不得产生有害干扰。
2. 本设备必须能够承受接收到的任何干扰，包括可能导致设备异常运行的干扰。

**警告：** 未经合规责任方明确批准而对本设备进行更改或改装，可能导致用户失去操作本设备的授权。
