## 产品简介

**PopStation mini** 是一款专为 Snapmaker U1 打印机设计的一款集成耗材收纳保存的移动工作平台,具备耗材防潮,保留自动进料以及兼容耗材烘干,打印机状态显示功能为一体可移动的产品。

- **耗材收纳防潮**:全封闭密封设计,可以有效隔绝潮湿空气,保持耗材干燥。
- **标配脚垫,兼容福马轮**:标配固定脚垫,可以稳定放置在桌面,兼容福马轮,可以方便打印机移动。
- **兼容 Panda Breath**:实现耗材边烘边打。
- **PC材质的可观察视窗**:使用耐高温的PC材质可观察视窗,清晰可见耗材余量。
- **兼容可拓展的 Panda RGB Controller 控制板**:通过绑定Snapmaker U1打印机,状态灯可以实时显示打印状态。同时可以个性化装饰打印空间。
- **钣金材质,坚固耐用**:整体结构采用钣金材质,顶面和地面采用激光焊接,既坚固耐用,又美观大方。
- **空间利用**:有效将Snapmaker U1打印机的桌面占用空间转移至机器下方,节省桌面空间。

## 机器设置

将 Snapmaker U1 开机,进入设置,需要进行完成以下三个步骤。

连接热点,并记录成功连接热点的 IP 地址。

<ImageView src={require("./img/popstation-mini-installation-27.webp").default} width="40%" />

进入"设备维护"选项,点击"高级模式",进入后点击同意并开启。

<ImageView src={require("./img/popstation-mini-installation-28.webp").default} width="40%" />

同样在"设备维护"选项下,点击"Root 权限",进入后下拉浏览全部内容后点击同意并开启。

<ImageView src={require("./img/popstation-mini-installation-29.webp").default} width="40%" />

打开电脑,将电脑连接与 Snapmaker U1 同一个 Wi-Fi 网络。打开电脑终端。输入:**ssh root@192.168.1.156** (替换为您U1 上面显示的链接WiFi的IP地址)后回车。若您首次进行该操作,需要您输入**yes**,后续则不用。然后输入密码:**snapmaker**后回车进入root模式。

:::info[注意]

请注意,这里将 192.168.1.156 替换为您实际连接的 Wi-Fi 的 IP 地址。

:::

<ImageView src={require("./img/popstation-mini-installation-30.webp").default} width="80%" />

进入 root 模式后,输入:**touch /oem/.debug**后回车,该命令用于将修改的文件数据持久化,否则每次开启U1则需要重新配置。

<ImageView src={require("./img/popstation-mini-installation-31.webp").default} width="80%" />

然后,输入:**vi /home/lava/klipper/klippy/extras/filament_feed.py**后回车,可以按**向下键**到504行找到 **maxval** 参数,按下**a**键进入编辑模式,将参数值1500调整到2500.按下**ESC**键退出编辑模式,输入(:wq)后回车。

<ImageView src={require("./img/popstation-mini-installation-32.webp").default} width="80%" />

打开浏览器,输入您 U1 上面显示的连接 Wi-Fi 的 IP 地址。打开**Configuration**选项,并打开**printer.cfg**配置文件。

<ImageView src={require("./img/popstation-mini-installation-33.webp").default} width="80%" />

进入后可以按下(CTRL + F)单独搜索**filament_feed left**,**filament_feed right**,将**preload_length**参数值由950修改到2000。然后点击保存后退出即可。

<ImageView src={require("./img/popstation-mini-installation-34.webp").default} width="80%" />
<ImageView src={require("./img/popstation-mini-installation-35.webp").default} width="80%" />

最后,将 Snapmaker U1 重新开机,并安装耗材进料即可。

<ImageView src={require("./img/popstation-mini-installation-36.webp").default} width="80%" />

至此,您完成了所有的安装和设置。

<ImageView src={require("./img/popstation-mini-installation-37.webp").default} width="60%" />

:::info[注意]

注意,打印时不建议通过 PopStation mini 使用 TPU 等柔性耗材。

:::

## 常见问题 FAQ

### Q1:设备上电并进料,出现缠料报错?

**解决方法:**

- 请逐一排查进料通道,定位出现问题的进料通道。
- 请仔细观察出现报错信息所在通道的耗材停在哪个位置。
- 若耗材已经从送料机出去但是在 PopStation mini 的四通后面没有看到耗材,可能是该通道的铁氟龙管没有插紧,可以重新取下并插紧,同时排查铁氟龙管头是否齐平,若存在倾斜角,请用切料器切平。
- 若耗材已经从 PopStation mini 的四通件出来,但是没有在 Snapmaker U1的进料管看到,同样排查铁氟龙管与插入 Snapmaker U1 时是否插紧,重复同样的排查动作。

### Q2:送料器已经连接15-pin排线,且将 Snapmaker U1 开机,但是插入耗材后进料器没有送料?

**解决方法:**

- 将没有送料的送料机取下,直接连接 Snapmaker U1 机身的送料机插头。
- 重新将 Snapmaker U1 关机后开机。
- 将耗材插入该送料机送料通道,观察是否正常送料？若无反映,说明送料机本身出现问题或者排线出现问题,可以联系 Snapmaker U1 打印机官方售后人员处理。若有反映且正常进料,需要进一步逐一排查 PopStation mini 配置的排线以及转接器。
- 可以将**所有排线插头**重新插拔一次,因为有可能已插头松动导致的供电异常。PopStation mini 内部的排线插头不好插拔,可以将转接器板子取下再进行插拔测试。
- 尝试将连接线进行重新插拔,若重新插拔后还是没有反映,需要逐一排查所有转接器和连接线,定位到具体的器件,定位问题后可以联系售后人员。
- 我们 PopStation mini 出厂前会进行全部电气自检,合格后才会正常发货。但是不排除运输过程中出现各种意外的情况,请出现问题时及时联系售后支持人员。

### Q3:送料器正常进料,但是送料的距离打印头还有一段距离时停止?

**解决方法:**

- 请检查在设置中是否忘记输入:touch /oem/.debug 命令,请参考上面的设置步骤进行。
- 请检查 Snapmaker U1 设置以及配置文件中**filament_feed**的参数,确保**preload_length**参数值为2000并保存。

### Q4:Panda RGB Controller Wi-Fi 连接失败或一直显示"连接中"?

**解决方法:**

- 确认 Wi-Fi 密码输入正确
- 确认路由器支持 2.4GHz(不支持纯 5GHz)
- 如果多次失败,尝试恢复出厂设置后重新配置

### Q5:Panda RGB Controller 无法扫描到打印机?

**解决方法:**

- 确认打印机已开机且联网
- 确认 Panda RGB Controller 和打印机在**同一局域网**内

### Q6:Panda RGB Controller 参数设置后重启丢失?

**解决方法:**

- 确认修改后点击了 **保存设置** 按钮

### Q7:如何恢复出厂设置?

1. 进入 **设置** 页面
2. 点击 **Factory Reset(恢复出厂设置)** 按钮
3. 确认后设备自动重启并清除所有配置

> 恢复出厂设置会清除所有配置(Wi-Fi,打印机绑定,参数设置等),请谨慎操作！

### Q8:如何通过主机名访问 Web UI?

默认主机名为 `PandaRGBController`,在浏览器输入:

```
http://PandaRGBController.local
```

如果无法访问,可以在 **Wi-Fi & IP** 页面查看设备 IP 地址,直接使用 IP 访问。
