# Introducing the BigTreeTech Open Wiki Translation Project

## Why Open i18n Translation Contributions?

We want more users to be able to read the Wiki in their preferred language. To achieve this, we have opened the project to community i18n translation contributions.

Instead of relying on a small group of maintainers to translate every document, community contributions help expand language coverage more quickly while continuously improving terminology and translation quality. Whether you're fixing a typo, translating a few paragraphs, or contributing an entire document, you're welcome to submit a Pull Request.

To make contributing as simple as possible, the entire i18n workflow is wrapped in a unified set of Yarn commands. Contributors only need to synchronize the translation files, edit the intermediate TOML files, and rebuild the translations. There is no need to interact directly with the underlying Python tools or manually maintain the generated i18n MDX files.

The following guide walks you through the complete i18n translation contribution workflow.

## Contributing to i18n Translations

### Prerequisites

Before you begin, make sure the following tools are installed:

- Git
- Node.js v24.x - v26.x
- Yarn v1 (will move to corepack and yarn v4 later)
- Python v3.10+

Install the project dependencies:

```bash
yarn install
```

Initialize the Python virtual environment:

```bash
yarn setup-venv
```

This command automatically creates and configures the Python virtual environment required by the project.

### Start Translating

First, synchronize the source document and generate the corresponding intermediate translation files:

```bash
yarn build-i18n --lang en -i docs/<file>
```

Where:

```text
docs/<file>
```

is the path to the original Chinese document you want to translate. For example:

```bash
yarn build-i18n --lang en -i docs/docs/board-docs/mmb-series/mmb-2/mmb-2.mdx
```

### Edit the Translation

`build-i18n` performs the following tasks:

1. Synchronizes the source document to the intermediate TOML translation file.
2. Generates the corresponding i18n MDX document using the current translations.

Edit the generated **intermediate TOML file**. Do **not** edit the generated i18n MDX file directly.

### Rebuild

After updating the translation, run the command again:

```bash
yarn build-i18n --lang en -i docs/<file>
```

The tool will regenerate the final i18n document using the latest TOML translations.

### Before Submitting

Before opening a Pull Request, make sure that:

- You have rerun `yarn build-i18n`.
- The translation is accurate.
- The document structure and line layout match the source document.
- Code, links, image paths, variables, and placeholders have not been modified.
- You have not edited the generated i18n MDX files directly.

Once everything looks good, you're ready to submit your [Pull Request](https://github.com/bigtreetech-beta/bigtreetech-wiki-neo/pulls).

## Request a New Language

If the language you'd like to contribute is not currently supported, you can request it by opening a GitHub [Issue](https://github.com/bigtreetech-beta/bigtreetech-wiki-neo/issues).

Please include:

- The language you would like to add.
- Its locale code (if known), for example `fr`, `de`, or `ja`.
- Any additional information that may help us prepare the translation files.

Once the language is added, you can follow the workflow above to start contributing translations.
